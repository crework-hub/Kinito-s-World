# Kinito's World

Трёхмерный парк в духе KinitoPET: низкополигональная картинка, туман, клетчатый пол и окно 640×480. Сделано на Python (pygame и OpenGL).

## Знакомство

В начале Кинито задаёт два вопроса. Оба экрана нарисованы кодом: деревянный фон, лист в клетку и рамка из листьев.

1. **Любимое время года.** Четыре пиксельные картинки: весна, лето, осень и зима. Картинку можно нажать или выбрать клавишами 1–4.
2. **Любимая еда.** Так же, картинками: пицца, бургер, суши и торт.

Дальше рисовалка, похожая на Paint. Нужно нарисовать пять картинок: счастье, грусть, лучшего друга, себя и того, кто стоит за спиной. Курсор там — полый круг, его видно и на чёрном, и на белом. Кнопка **Готово** или Enter сохраняет рисунок.

Потом расстановка мебели на плане двухэтажного дома. Дом в начале пустой. Предметы лежат в нижней панели: их перетаскивают на этаж, колесом мыши приближают план, клавишей R или правой кнопкой поворачивают. Кнопка **1 этаж** / **2 этаж** переключает уровень, **По умолчанию** ставит готовую обстановку, **Готово** или Enter заканчивает расстановку. В стену, на лестницу и в дверной проход мебель не встаёт.

Ответы, рисунки и расстановка сохраняются для текущего пользователя Windows. После перезапуска знакомство заново не начинается.

## Парк и «Твой мир»

Дальше можно гулять по парку, кататься на аттракционах и зайти в мини-игры. В парке играет общая тема.

Американские горки в конце въезжают в шестиугольную дыру и идут вперёд по длинному белому проходу. За ним открывается «Твой мир»: лес, музыка и двухэтажный дом зависят от выбранного сезона. На стенах висят рисунки, на столе стоит выбранная еда, а мебель в комнатах стоит так, как её поставили на плане. Каждая модель собрана из нескольких фигур: ножки, дверцы, подушки, краны. Из дома можно вернуться в парк через такой же проход.

## Как запустить

Нужны Python 3 и видеокарта с OpenGL. При установке Python отметь **Add python.exe to PATH**. Если этой галочки нет, подойдёт и лаунчер `py`.

Один раз поставь зависимости двойным щелчком по `install.bat` в папке проекта. Он сам вызовет `python` или `py -3` и выполнит `pip install -r requirements.txt`. В конце окно напишет, получилось ли.

То же самое можно поставить вручную:

```bash
python -m pip install -r requirements.txt
```

Если команда `python` не находится:

```bash
py -3 -m pip install -r requirements.txt
```

Зависимости: `pygame-ce`, `PyOpenGL`, `numpy`, `opencv-python`.

Дальше игру запускает `play.bat` — двойной щелчок в той же папке. Он тоже сам вызывает `python` или `py -3`.

Вручную то же самое:

```bash
python kinito_park.py
```

## Управление

| Клавиша | Действие |
| --- | --- |
| WASD | Ходьба |
| Shift | Бег |
| Мышь | Обзор; в опросе и в расстановке — выбор |
| ПКМ | Приближение в парке; поворот мебели на плане |
| Колесо | Крупнее или мельче план дома |
| E | Сесть на аттракцион, открыть дверь, поговорить, начать мини-игру |
| 1–4 | Ответы в опросе |
| R | Повернуть выбранную мебель |
| Enter | Сдать рисунок или закончить расстановку |
| F2 | Размер пикселей |
| F1 | Скрыть интерфейс |
| M | Музыка |
| Esc | Выход |

В рисовалке: карандаш, кисть, заливка, линия и ластик. Цвет выбирается внизу окна.

Сохранение лежит в папке `saves` рядом с игрой, отдельно для каждого пользователя Windows. Чтобы пройти знакомство заново, удали свою папку оттуда.
