# Kinito's World

Трёхмерный парк в духе KinitoPET: низкополигональная картинка, туман, клетчатый пол и окно 640×480. Сделано на Python (pygame и OpenGL).

В начале Кинито спрашивает любимое время года и любимую еду, потом просит нарисовать пять картинок в рисовалке, похожей на Paint: счастье, грусть, лучшего друга, себя и того, кто стоит за спиной. Ответы и рисунки сохраняются на этого пользователя Windows. После перезапуска опрос заново не начинается.

Дальше можно гулять по парку, кататься на аттракционах и зайти в мини-игры. Американские горки в конце въезжают в шестиугольную дыру и привозят в «Твой мир»: лес и двухэтажный дом зависят от выбранного сезона, на стенах висят твои рисунки, на столе стоит выбранная еда. Из дома можно вернуться в парк через такой же проход.

## Как запустить

Нужны Python 3 и видеокарта с OpenGL.

```bash
pip install -r requirements.txt
python kinito_park.py
```

На Windows, если команда `python` не находится:

```bash
py -m pip install -r requirements.txt
py kinito_park.py
```

Зависимости: `pygame-ce`, `PyOpenGL`, `numpy`.

## Управление

| Клавиша | Действие |
| --- | --- |
| WASD | Ходьба |
| Shift | Бег |
| Мышь | Обзор |
| ПКМ | Приближение |
| E | Сесть на аттракцион, открыть дверь, поговорить, начать мини-игру |
| 1–4 | Ответы в опросе |
| Enter | Сдать рисунок |
| F2 | Размер пикселей |
| F1 | Скрыть интерфейс |
| M | Музыка |
| Esc | Выход |

В рисовалке: карандаш, кисть, заливка, линия и ластик. Цвет выбирается внизу окна. Кнопка **Готово** сохраняет рисунок.

Сохранение лежит в папке `saves` рядом с игрой, отдельно для каждого пользователя Windows. Чтобы пройти знакомство заново, удали свою папку оттуда.
